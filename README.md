# Course Project Weather App

This mobile weather application provides users with real-time weather tracking, detailed forecasting, and the ability to seamlessly manage favorite locations. By combining up-to-the-minute conditions with multi-day forecasts, the app empowers users to make informed decisions about their daily activities and travel plans, all within an intuitive and responsive interface.

Built with a modern mobile development stack, the application leverages React Native and Expo to deliver a highly optimized cross-platform experience. It utilizes Expo Router for robust navigation, Expo Location for accurate user positioning, and integrates Expo Haptics and Sensors to provide engaging, tactile feedback. Furthermore, the codebase is fully typed with TypeScript for enhanced maintainability, and it employs Reanimated to ensure smooth, performant animations throughout the user interface.

## Onboarding

To get started with the project, use the following standard commands to install dependencies and run the application:

```bash
# Install dependencies
npm install

# Start the Expo development server
npm start
```

Once the server is running, you can press `i` to launch the app on an iOS simulator, `a` to open it on an Android emulator, or scan the QR code with the Expo Go app on your physical device.
